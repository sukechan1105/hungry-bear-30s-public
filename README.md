# Hungry Bear 30s

鮭を顔でキャッチしてクマを育てる、30秒のブラウザゲームです。コンボで成長し、ラスト5秒は左右端の毒キノコに注意！ 10段階の称号と、ブラウザごとの自己ベストを楽しめます。オンラインランキングはありません。

公開予定URL：https://sukechan1105.github.io/hungry-bear-30s-public/ （公開作業は未実施）

## 遊び方

- 「スタート」を押すと3秒のカウントダウン後に開始。
- PC：左右キー、またはマウスで左右に移動。
- スマホ：ゲーム画面を指でスライド。
- 鮭を顔でキャッチして成長。毒キノコに当たると縮小し、コンボがリセットされます。
- 「あそびかた」で説明を確認でき、結果画面からRETRY・Xへの結果シェアができます。シェアは本人が投稿を確定する方式です。

## 使用技術・制作

HTML / CSS / JavaScript / Canvas 2D。Codexを活用し、実装・デザイン調整・動作検証を進めて制作しました。クマ・鮭・毒キノコ・森と川はコードで描画しています。

外部ライブラリ、ビルド、APIキー、サーバー側処理は不要です。ゲーム動作に画像・音声の別ファイルは不要です。SNSのプレビュー用画像ogp.pngは別途同梱しています。index.htmlをブラウザで開くか、静的HTTPサーバーで配信できます。自己ベストはlocalStorageに保存され、ブラウザや公開元が変わると別の記録になります。ローカルでの記録は公開後に自動移行されません。

## 公開用ファイル

このフォルダの**中身**をGitHubリポジトリのルートへ配置する方式を想定しています。index.htmlがルートに来るようにしてください。.nojekyllは静的ファイルをそのまま配信するための空ファイルです。.gitignoreはGitへの混入を防ぐ補助であり、既に追跡済みのファイルを除外するものではありません。

OGP画像は採用済みの `ogp.png`（1200×630px・PNG）を同梱しています。index.htmlのog:image・twitter:imageは公開予定URLの画像を参照し、twitter:cardはsummary_large_imageに設定済みです。画像もindex.htmlと同じ階層にアップロードしてください。実際のカード表示は公開後に確認します。
